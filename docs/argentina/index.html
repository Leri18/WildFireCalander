Limits

A gap in satellite coverage looks like a quiet month; it is not the same as no fire. Months before July 2002 rest on one satellite (Terra) and are the least certain. The uncertainty range is valid for the whole country only. Counts are vegetation fires (FIRMS type 0); static industrial sources are excluded. The archive ends in December 2025.

Data: NASA FIRMS, MODIS Collection 6.1 (Terra, Aqua) and VIIRS 375 m (S-NPP, NOAA-20), country yearly summary archive.
